# Настройки запуска и базовая защита веб службы
В этой работе была проделана работа с настройками приложения и реализована базовая защита веб-службы.

## Запуск
Для запуска программы пропишите следующую команду:
``` zsh
npm i && npm run dev
```

## О программе
### Настройки:
Чтение настроек происходит из трех источников, в порядке приоритета:<br>файл конфигурации < переменные окружения < аргументы командной строки.
### Защита:
Разрешини только запросы с доверенных источников, а также добавлено ограничение частоты запросов, чтобы один источник не мог завалить службу. Кроме того, добавлены защитные заголовки ответа, чтобы снизить риски простых атак через встраивание и кэширование.
